# prisma-de02-sandbox

Sandbox **não autoritativo** da PRI-230 (DE-02, D230-3 A). Contém só um verificador stub e fixtures sintéticas: nenhum código, dado, histórico ou knowledge do consumidor. Nada aqui é registro do Prisma. Serve para demonstrar o mecanismo de host (strict + check obrigatório + auditoria) com casos negativos.
